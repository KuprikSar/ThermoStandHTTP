Проект прошивки для **ESP32-S3**, которая измеряет температуру с **PT100 (RTD)** через микросхемы **MAX31865** по общей шине SPI и публикует результаты в **веб-интерфейсе** и через **HTTP API**.

Текущая целевая конфигурация стенда: **32 канала PT100/MAX31865**.

Проект подходит для стенда проверки и сравнения датчиков, термокамеры, нагревателей, отладки железа и контроля нескольких температурных точек одновременно.

---

## Возможности

- ✅ Чтение температуры с PT100 через MAX31865 по SPI
- ✅ Поддержка до **32 температурных каналов**
- ✅ Две SPI-шины для всех MAX31865
- ✅ Выбор активного MAX31865 через отдельные CS-линии или через дешифратор каналов
- ✅ Веб-интерфейс с таблицей температур, статусами и автообновлением
- ✅ HTTP API для получения данных внешними скриптами, логгером, Grafana и т.д.
- ✅ Диагностика ошибок MAX31865: обрыв, короткое замыкание, fault flags
- ✅ Подсветка статусов и перегрева в таблице
- ✅ Работа по Wi-Fi HTTP локальный сервер

## Архитектура на 32 датчика

Каждый канал состоит из:

- одного датчика **PT100**
- одного преобразователя **MAX31865**
- индивидуального выбора чипа по линии **CS**

Все MAX31865 сидят на одной SPI-шине:

- `SCLK` общий
- `MOSI` общий
- `MISO` общий
- выбор активного чипа выполняется через `CS`

Для 32 каналов удобнее не заводить 32 отдельные GPIO под CS, а использовать дешифратор адреса.

Типовая схема выбора канала:

- 4 адресные линии `A0..A3` выбирают один из 16 выходов дешифратора
- для 32 каналов используется два банка по 16 каналов
- дополнительная линия выбора банка включает нужный дешифратор или нужную группу каналов
- выход дешифратора работает как активный `CS` для конкретного MAX31865

Если используется **IN74HC154 / 74HC154**, нужно помнить:

- выходы дешифратора активны низким уровнем
- выбранный выход уходит в `LOW` и может использоваться как `CS` MAX31865
- невыбранные выходы остаются в `HIGH`
- входы разрешения дешифратора активны низким уровнем
- если дешифратор должен быть постоянно включен, его enable-входы можно держать в `LOW`, например подключить к GND

## Железо

**Минимум:**

- ESP32-S3 devkit
- 32 микросхемы MAX31865 и 32 готовых модуля MAX31865
- 32 датчика PT100
- дешифратор CS IN74HC154
- питание 3.3 В для IN74HC154

**SPI:**

| Сигнал | Назначение |
|---|---|
| `SCLK` | общий SPI clock для всех MAX31865 |
| `MOSI` | общий SPI MOSI |
| `MISO` | общий SPI MISO |
| `CS` | выбор конкретного MAX31865, напрямую или через дешифратор |

**Рекомендации по разводке:**

- держать линии SPI короткими
- на длинных линиях SPI предусмотреть последовательные резисторы 22..100 Ом
- внимательно разводить землю около аналоговой части MAX31865
- не вести провода PT100 рядом с силовыми цепями и ШИМ-нагрузками
- для длинных проводов PT100 желательно использовать 4-проводную схему
- не оставлять адресные и enable-входы дешифратора в воздухе

## Веб-интерфейс

Главная страница показывает таблицу по всем 32 каналам.

Обычно в таблице есть:

- номер канала
- температура, °C
- статус канала
- fault-код MAX31865
- состояние датчика: OK, ошибка, нет данных и т.д.

Логика подсветки:

- нормальные значения подсвечиваются штатным цветом
- ошибки MAX31865 выделяются отдельно
- температуры выше заданного порога, например выше 100 °C, могут подсвечиваться красным

Страница может обновляться автоматически, например раз в 1 секунду.
